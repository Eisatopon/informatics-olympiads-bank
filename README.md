# World Informatics Olympiads Bank

Public site of the World Informatics Olympiads Bank (eisatopon.gr): informatics olympiad tasks — the International Olympiad in Informatics (IOI) first — in English, task statements only (with constraints, subtasks, limits and sample tests).

Live: https://eisatopon.github.io/informatics-olympiads-bank/

This repository holds only the files the site loads. The tasks remain the work of their authors and scientific committees.
Sister projects: [World Mathematical Olympiads Bank](https://eisatopon.github.io/national-olympiads-bank/), [World Physics Olympiads Bank](https://eisatopon.github.io/physics-olympiads-bank/), [World Chemistry Olympiads Bank](https://eisatopon.github.io/chemistry-olympiads-bank/).
